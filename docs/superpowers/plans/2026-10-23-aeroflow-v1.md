# AeroFlow v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static web dashboard (GitHub Pages) that runs a real-time 2D Lattice Boltzmann simulation of air flowing past a cylinder, square, flat plate, NACA 0012 and NACA 2412. Users control velocity, object, angle and size, and read Re, Cd, Cl and St.

**Architecture:** A CPU reference solver in TypeScript is the executable spec of the physics. It is unit-tested against physics benchmarks. Two GPU backends implement the same algorithm: WebGPU compute (primary) and WebGL2 fragment ping-pong (fallback). Both must match the CPU solver within tolerance (parity tests). A backend-agnostic `SimController` owns parameters, resets, ramps, divergence recovery and readbacks. The UI (layout A) and the charts sit on top of it.

**Tech Stack:**
- Vite 5 + TypeScript 5 (strict), no UI framework.
- Vitest for unit and physics tests; Playwright (Chromium) for browser, GPU-parity and e2e tests.
- uPlot for the charts.
- WGSL (WebGPU) and GLSL ES 3.00 (WebGL2) shaders, imported as strings via Vite `?raw`.
- GitHub Actions deploying to GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-23-aeroflow-design.md`

## Global Constraints

- **Language:** every user-visible string is pt-BR.
- **Fluid:** air only, ν = 1.5e-5 m²/s, incompressible. The velocity control is capped at 100 m/s (Mach ≤ 0.3).
- **Hosting:** fully static. No runtime network calls except loading the page's own assets. `vite.config.ts` uses `base: './'`.
- **Physics must be real:** every pixel of the flow field comes from the simulation. No decorative animation.
- **Fidelity warning:** exact copy `⚠ Re alto: modelo de turbulência, valores aproximados`. It is shown whenever `Re / Lcells > 10` (Lcells = characteristic length in lattice cells for the current preset and object).
- **2D note** (ⓘ), exact copy: `Esta simulação é 2D. Acima de Re ≈ 190, o escoamento real ao redor de um cilindro é tridimensional; os valores aqui não capturam esses efeitos.`
- **Divergence message**, exact copy: `A simulação ficou instável e foi reiniciada.`
- **Unsupported-browser message**, exact copy: `Seu navegador não suporta WebGPU nem WebGL2 com texturas float. Use uma versão recente do Chrome, Edge ou Firefox.`
- **Performance target:** ≥ 30 fps, and a von Kármán wake visible ≤ 10 s after reset, on the Alta preset on a laptop with an integrated GPU.
- **Presets:**

  | Preset | Grid (W×H) | Lcells (blunt) | chord cells (airfoil) |
  |---|---|---|---|
  | Baixa | 288×144 | 12 | 24 |
  | Média | 432×216 | 18 | 36 |
  | Alta | 576×288 | 24 | 48 |

  Blockage D/H = 1/12, W = 2H. (Ruling 2026-10-24: the original D/H = 1/6 raised cylinder Cd to 1.76 and St to 0.198 at Re=100, outside spec §7.)

- **WebGL2 backend:** only Baixa and Média. Alta is disabled in the selector, with the tooltip `Disponível apenas com WebGPU`.
- **Lattice velocity:** u_lb = 0.08 at target speed. ν_lb = u_lb·Lcells/Re. τ0 = 0.5 + 3ν_lb.
- **Smagorinsky constant:** Cs = 0.1.
- **Defaults on first load:** cylinder, D = 0.01 m, U = 0.15 m/s (Re = 100), α = 0°, field = vorticidade.
- **Control ranges:**
  - velocity: 0.001–100 m/s, log slider;
  - size: 0.001–2 m, log slider;
  - angle: −20° to 90°, linear, 0.5° step.
- `.superpowers/` is in `.gitignore`.

## Review Focus

1. **Extreme parameter combos:** Re up to ~1.3e7 (100 m/s, 2 m) on the Baixa preset. Expected: the simulation stays finite, or auto-recovers with the divergence message. Never a black screen. Test added in Task 3 (CPU) and Task 10 (controller recovery).
2. **Continuous slider dragging or object switching mid-ramp.** Expected: no stale geometry, no crash, no NaN, and only the latest parameters take effect. Test added in Task 10.
3. **No WebGPU, and WebGL2 without `EXT_color_buffer_float`.** Expected: falls back to WebGL2, or shows the unsupported-browser message. Never a blank page. Test added in Task 12 (e2e with WebGPU disabled, and with a stubbed context).
4. **Backgrounded tab** (rAF paused, then a huge frame delta on return). Expected: no runaway step count, and the adaptive step count is not driven down. Test added in Task 10.
5. **Phone width (375 px) and projector width (1920 px).** Expected: the layout fits with no horizontal scroll, and the canvas keeps the grid aspect ratio. Test added in Task 12.

### Task 3: CPU reference solver — collision, streaming, domain boundaries

**Files:**
- Create: `src/physics/lbm-cpu.ts`
- Test: `tests/unit/lbm-cpu.test.ts`, `tests/physics/poiseuille.test.ts`, `tests/physics/stability.test.ts`

**Interfaces:**
- Consumes: `d2q9.ts`, `Geometry`, `CS_SMAG`.
- Produces:
  - `class LbmCpu`
    - `constructor(geom:Geometry, tau0:number, uIn:number, opts?:{bouzidi?:boolean})` (bouzidi defaults to true from Task 4 on)
    - `setTau0(t:number)`, `setInlet(ux:number, uy:number)`, `setGeometry(geom:Geometry)` (semantics as in `SimBackend.setGeometry`, Task 7)
    - `step(): void`
    - `rho:Float32Array`, `ux:Float32Array`, `uy:Float32Array` (macroscopic, updated each step)
    - `f:Float32Array` (layout `f[i*W*H + cell]`)
    - `initUniform(ux:number, uy:number)`
    - `addKick(x0:number, y0:number, x1:number, y1:number, dvy:number)`
    - `lastForce: {fx:number, fy:number}` (filled in Task 4; 0 for now)
  - `feq(i, rho, ux, uy): number`

**Algorithm (the GPU shaders must mirror this exactly):**

1. **Collision, per fluid cell: regularized BGK with Smagorinsky.**
   - Compute rho, u, and `feq_i`.
   - Compute `Π_neq = Σ c_i c_i (f_i − feq_i)` (components xx, xy, yy).
   - Regularized non-equilibrium part: `f_neq_i = (9/2)·W_i·(Q_i : Π_neq)`, where `Q_i = c_i c_i − (1/3) I`.
   - `|Π| = sqrt(Πxx² + Πyy² + 2Πxy²)`.
   - Effective relaxation time: `τ = 0.5·(τ0 + sqrt(τ0² + 18·√2·Cs²·|Π|/rho))`.
   - Post-collision value: `f*_i = feq_i + (1 − 1/τ)·f_neq_i`.
2. **Streaming (pull):** `f_i(x) = f*_i(x − c_i)`, except in these cases:
   - **x − c_i is solid:** handled by Bouzidi in Task 4. For now, use simple bounce-back: `f_i(x) = f*_{OPP i}(x)`.
   - **x − c_i has y outside [0, H):** free slip. Use `f*_{MIRROR_Y i}` taken from `(x.x − c_ix, x.y)`, clamped in x.
   - **x is at column 0:** inlet. `f_i = feq_i(rho(1, y), uIn)`.
   - **x is at column W−1:** fixed-pressure outlet (ρ = 1) by non-equilibrium extrapolation, applied after streaming: `f_i(W−1,y) = feq_i(1, u(W−2,y)) + (f_i(W−2,y) − feq_i(ρ(W−2,y), u(W−2,y)))`, with ρ and u computed from the post-streaming f at W−2. (Ruling 2026-10-24: a zero-gradient copy made total mass grow without bound.)
3. Solid cells hold `feq(1, 0, 0)` and are never read as fluid.

### Task 4: Bouzidi boundaries and momentum-exchange force

**Files:**
- Modify: `src/physics/lbm-cpu.ts`
- Test: `tests/unit/lbm-force.test.ts`

**Interfaces:**
- Produces: `LbmCpu.lastForce` is filled every step, in lattice units, as the force on the body.

**Algorithm.** For each link `(x_f, ī)` in `geom.links`: the solid lies along `c_ī`, `q = geom.q[x_f, ī]`, and `i = OPP ī` is the incoming direction.
- If `q < 0.5`: `f_i(x_f) = 2q·f*_ī(x_f) + (1−2q)·f*_ī(x_f + c_i)`.
- If `q ≥ 0.5`: `f_i(x_f) = f*_ī(x_f)/(2q) + (2q−1)/(2q)·f*_i(x_f)`.
- If `x_f + c_i` is solid: fall back to `f_i = f*_ī(x_f)`.
- Force: `F += c_ī·(f*_ī(x_f) + f_i(x_f))`, summed over all links.

### Task 5: Analysis — coefficients, moving average, Strouhal, steady detector

- Produces:

  - `class CoeffTracker`
    - `constructor(convectiveSteps:number)`, where convectiveSteps = Lcells/uLb
    - `push(step:number, cd:number, cl:number): void`
    - `reset(): void`
    - `mean(): {cd:number, cl:number}`: averaged over the last full Cl period when periodic, otherwise over the last 2·convectiveSteps

    - `isSteady(): boolean`: true when ≥ 10·convectiveSteps have passed since reset, and the mean Cd and Cl over the last two consecutive averaging windows differ by < 2%.

**Interfaces:**
- Produces, in `types.ts`:

```ts
export interface SimBackend {
  readonly kind: 'webgpu' | 'webgl2' | 'cpu';
  init(geom: Geometry, tau0: number, uIn: number): Promise<void>; // also used for reset
  setGeometry(geom: Geometry): void; // same grid size; keeps f, newly-solid → feq(1,0,0), newly-fluid → feq(1,0,0)
  setTau0(t: number): void;
  setInlet(ux: number, uy: number): void;
  initUniform(ux: number, uy: number): void;
  addKick(x0: number, y0: number, x1: number, y1: number, dvy: number): void;
  step(n: number): void;                       // n steps; force computed on the last one
  readForce(): Promise<{ fx: number; fy: number; finite: boolean }>;
  readMacro(): Promise<{ rho: Float32Array; ux: Float32Array; uy: Float32Array }>; // tests/parity only
  render(field: 'vorticity' | 'speed' | 'pressure', canvas: HTMLCanvasElement): void; // Task 9
  destroy(): void;
}
```

- **`cpu-backend.ts`** wraps `LbmCpu`. `render` draws to a 2D canvas using `colormaps.ts` (stub until Task 9).
- **WebGPU** uses storage buffers: f (two buffers, ping-pong, `9·W·H` f32), solid (u32), q (`9·W·H` f32), links (i32 pairs), forceOut (`2·nLinks` f32), and a uniform block `{W, H, tau0, cs, uInX, uInY}`.
  - Compute passes per step: (a) collide + stream (pull) + Bouzidi, one invocation per cell, workgroup 8×8; (b) outlet copy; (c) on the last step only, per-link force into forceOut.
  - `readForce` maps a staging buffer and sums on the CPU. `finite` is false if any value is NaN or Inf.
- **`parity.ts`:**
  - reads `?backend=webgpu|webgl2`;
  - builds a square on Baixa at Re=100, plus the same kick;
  - on both the CPU backend and the chosen GPU backend, runs 100 steps, calls `setGeometry` with the square rotated to α = 10°, then runs 100 more steps;
  - exposes `window.parityResult = { maxAbsDiffU, forceRelDiff }`.

### Task 10: SimController

**Files:**
- Create: `src/sim/controller.ts`
- Test: `tests/unit/controller.test.ts` (using `CpuBackend` on a 60×24 test preset, injected)

**Interfaces:**
- Consumes: `SimBackend`, `toLattice`, `makeShape`, `rasterize`, `objectCenter`, `CoeffTracker`, `toCoeffs`, `PRESETS`.
- Produces:

```ts
export interface SimState {
  re: number; cd: number; cl: number; st: number | null;
  cdInst: number; clInst: number; step: number;
  simTimePhys: number; slowMotion: number;           // slowMotion = wall s per physical s
  stepsPerFrame: number; fps: number;
  fidelityWarning: boolean; steady: boolean; message: string | null;
}
export class SimController {
  constructor(backend: SimBackend, preset: PresetId, initial: PhysParams);
  setParams(p: Partial<PhysParams>): void;
  setPreset(p: PresetId): Promise<void>;
  frame(nowMs: number): Promise<SimState>;           // called from rAF
  onState(cb: (s: SimState) => void): void;
}
```

**Behaviour:**
- **Reset** happens on object, size or preset change: rasterize, `init`, `initUniform(uLb, 0)`, then kick (as in Task 6).
- **Velocity or angle change (spec: no restart):**
  - Velocity only changes τ0, because uLb stays fixed. Apply it at once with `setTau0` and reset the `CoeffTracker`.
  - Angle re-rasterizes and calls `backend.setGeometry(geom)`, which keeps the flow field. Reset the `CoeffTracker`.
- **Debounce:** geometry changes are coalesced. At most one `setGeometry` or `init` per frame, using the latest params.
- **Adaptive steps:**
  - start at 10;
  - after each frame, if dt < 25 ms then +2, if dt > 34 ms then −2;
  - clamp to [1, 300];
  - frames with dt > 250 ms are ignored for adaptation and fps.
- **Readback:** `readForce` once per frame, feeding `CoeffTracker`.
- **Divergence:** if `finite` is false, reset and set `message = COPY.diverged` for 4 s.
- **Time:**
  - `simTimePhys = step·dtPhys`;
  - `slowMotion = (wall time per frame)/(stepsPerFrame·dtPhys)`.

  - after `setParams({kind:'square'})`, `init` is called once;
